## 🎮 Manual de Uso e Interacción
Para mantener con vida a Python Copérnico, el usuario debe gestionar 3 barras de estado que disminuyen dinámicamente con el tiempo:

1. **Carga de Batería / Energía (Tecla `C`):** Al presionar la tecla **C**, la víbora toma un *Café de Sistemas* para recargar energías.
2. **Nivel de Código / Ánimo (Tecla `P`):** Al presionar la tecla **P**, la víbora ejecuta scripts en Python para mantener alto su nivel de programación.
3. **Limpia de Bugs / Salud (Tecla `B`):** Al presionar la tecla **B**, la víbora realiza *debugging* para solucionar errores de sintaxis (*Syntax Errors*).

### Expresiones de la Mascota:
* **Estado Compilando (Feliz):** Ojos oscuros con reflejos brillantes e indicadores estables (> 30%).
* **Estado Cansado:** Ojos cerrados/entornados si la batería baja del 30%.
* **Estado Buggeado:** Ojos con cruz roja (Error de Bug) si la salud de código cae por debajo del 30%.
